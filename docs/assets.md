# Artwork and previews

`codex-monitor-icon.png` was created with the built-in image-generation tool. `codex-monitor-icon.ico` contains the same artwork at seven Windows icon sizes, from 16 to 256 pixels. Both are distributed with this project's MIT license.

Prompt:

> Create one polished Windows desktop application icon for Codex Monitor, a local AI activity monitor. Square composition. A bold, front-facing desktop monitor silhouette with a short pedestal, deep midnight navy glass and soft metallic bevels, with a vivid mint green central glowing hub and five simple connected satellite dots on its screen, suggesting a live activity radar. A premium dimensional app icon, clean and extremely legible at 32–64 pixels. Large simple shapes, thick luminous strokes, restrained mint glow, minimal fine detail. Monitor fills most of the square with comfortable margins. Transparent background outside the monitor silhouette. No text, no letters, no numbers, no watermark, no mockup desktop, one icon only.

`docs/demo.jpg` shows only the built-in simulated event tour. No actual user's session data appears in the image.

`docs/demo.gif`, `docs/demo.mp4`, and the three gallery images were captured from the actual browser UI with the server pointed to an empty temporary sessions directory. The recording uses only the built-in simulated tour, played at 4× speed. The video contains no audio. Screenshots do not include the desktop or browser chrome.
