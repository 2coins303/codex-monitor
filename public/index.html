Your local activity map

This companion reads Codex’s session logs on this PC and serves a small status view on 127.0.0.1. It makes no external network requests and needs no API key.

The map displays tool names, short folder/file names, website hosts, command types, counts, timing, model name and reported context usage. It does not display prompts, replies, reasoning, full commands, URL paths or tool result contents. Consecutive visits to one station fold together; select +N to expand them. Scrolling into history holds your place; Back to live resumes the rolling feed.

Events appear when the log is written, which can be delayed. Nested calls share their parent batch’s completion time; an error in a batch is marked “Batch error” because the exact failing call may be unknown. The orbit at Agents represents an agent tool call in progress, not the full lifetime of a child agent. Model rows count distinct usage reports, not timed model requests. The route line connects recent tool stations; clock hands mark calls open for at least 3 seconds. Error badges count errors in the retained feed.

Context is the last reported input-token count divided by the reported window. Counts cover the loaded log segment; large sessions load a recent segment. Codex log formats may change after app updates.
